## 会话管理模块 开发记忆

- 关键决策：双数据库架构（服务层 MySQL + agent 层 SQLite），两个独立 engine/session 隔离，MYSQL_DATABASE_URL 通过 os.getenv 读取避免密码硬编码到代码默认值
- 实现要点：Conversation/Message ORM 模型一对多 + CASCADE 硬删除；thread_id 由 uuid4 服务端生成；列表接口分页返回 PaginatedConversations；消息路由路径改为 messages/{conversation_id}
- 踩坑记录：Pydantic model_validate 触发 SQLAlchemy relationship 懒加载导致 MissingGreenlet，改为手动构建 ConversationDetailOut（先转 ConversationOut 再 dump+构造）；MySQL 密码含 @ 需 URL 编码为 %40；aiomysql 需单独安装
- 后续待办：chat 接口需对接 Conversation 模型实现消息持久化；生产环境需配置 MySQL 连接池参数；消息接口需增加 conversation_id 归属校验
